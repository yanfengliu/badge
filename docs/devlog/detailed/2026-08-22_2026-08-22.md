## Saying authoring became independent and non-destructive

**Timestamp:** 2026-08-22

**Action:** Clarified that Badge Atelier can generate or regenerate a one-line saying and always lets the user write the line directly.

**Result:** Saying generation now has a provider-neutral boundary separate from art generation. A retry creates a pending proposal, preserves the accepted or handwritten line until explicit acceptance, and cannot change the selected art or appearance.

## Badges became interactive three-dimensional artifacts

**Timestamp:** 2026-08-22

**Action:** Promoted the badge from a layered visual treatment to a real-time 3D object that can be rotated, zoomed, and examined under adjustable lighting with a mouse.

**Result:** Product and visual contracts now require genuine geometry, physical material response, front-to-back inspection, object and light modes, reset and keyboard controls, reduced-motion behavior, GPU recovery, and a multi-angle fallback. Architecture stores an engine-neutral render recipe while keeping camera, light, scene, and GPU state ephemeral.

**Reasoning:** A flat image with a hover tilt cannot create the physical weight the owner wants. Separating durable construction from renderer state preserves the local archive, permits future engine changes, and avoids checking one heavy mesh into Git for every personal badge.

**Validation:** Product, visual, roadmap, policy, architecture, decision, backup, accessibility, and test contracts describe the same 3D behavior. Documentation syntax, links, policy mirroring, whitespace, binary limits, and secret checks pass, and two independent reviewers completed clean follow-up passes.

**Code reviewer comments:** Independent review exposed first-run fallback, baked-construction source art, owner-attribution, recipe portability, cache fingerprint, input-state, keyboard, resource-lifecycle, and spike-gate gaps. The final contract resolves them with a renderer-independent fallback, source-versus-construction separation, D-011/D-012 authority split, golden recipe semantics, explicit engagement commands, idempotent session disposal and stress tests, and measurable Phase 0 exit criteria.
