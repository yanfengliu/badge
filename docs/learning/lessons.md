# Lessons

A staging area, not a destination. A lesson lands here the session it is learned, in one line, anchored to a measurement, commit, or test id, and naming the gate it is waiting for — a test, a lint rule, a schema check, a fixed command.

An entry is deleted in the commit that lands its gate, and a gate counts only once it has been made to go red by reintroducing the defect. Every session in this repo pays to read whatever sits here, so the gate comes as early as it can be written.

An entry that can name no gate is not a lesson: fleet-wide knowledge is staged in [canon-candidates.md](canon-candidates.md) for the constitution, repo-only knowledge goes to [local-rules.md](../policies/local-rules.md), and the rest is folklore and is dropped.

Each rule links into [lessons-evidence.md](lessons-evidence.md), which holds the war story and the anchor. Retired gates and the mutations that proved them are recorded in [gate-proofs.md](gate-proofs.md). Defects the user reported stay in [defect-register.md](defect-register.md) even after they are gated.
